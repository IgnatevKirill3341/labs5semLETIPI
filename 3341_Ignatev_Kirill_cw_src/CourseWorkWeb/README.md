## Общее описание проекта

Это полнофункциональная игра-платформер, реализованная на чистом JavaScript (ES6) без использования фреймворков. Игра представляет собой 2D сайд-скроллер в японской тематике с самураем в главной роли. Игрок должен пройти через уровни, сражаясь с врагами, собирая бонусы и избегая препятствий.

### Основные особенности:
- **2 уровня игры** с различной сложностью
- **Система менеджеров** для управления различными аспектами игры
- **Интеллектуальные враги** с тремя типами поведения
- **Система бонусов** с тремя типами
- **Таблица рекордов** с сохранением в localStorage
- **Поддержка Tiled Editor** для создания уровней
- **Система звука** с генерацией через Web Audio API и загрузкой MP3 файлов
- **Видео-фоны** для экранов меню, победы и поражения
- **Система анимаций** для всех персонажей
- **Физика** с гравитацией и коллизиями

## Технические детали

### Используемые технологии:
- **JavaScript ES6** - чистый JavaScript без фреймворков
- **HTML5 Canvas API** - для отрисовки игры
- **Web Audio API** - для генерации звуков и воспроизведения аудио
- **HTML5 Video** - для видео-фонов экранов
- **LocalStorage API** - для сохранения рекордов
- **ES6 Модули** - для организации кода
- **Fetch API** - для загрузки уровней и ресурсов
- **Tiled JSON Format** - для уровней

### Требования:
- Современный браузер с поддержкой ES6 модулей
- HTTP сервер (нельзя открывать через `file://` из-за CORS)
- Разрешение экрана: рекомендуется 1024x768 или выше

## Архитектура игры

### Паттерны проектирования:

1. **Модульная архитектура** - код разделен на отдельные модули (ES6 modules)
2. **Observer (Наблюдатель)** - EventManager для распространения событий
3. **Manager Pattern** - отдельные менеджеры для различных систем
4. **Entity-Component System** - базовый класс Entity для всех игровых объектов
5. **State Machine** - управление состояниями игры (menu, playing, gameover, victory)

### Основные системы:

1. **GameManager** - центральный координатор всех систем
2. **PhysicsManager** - физика движения и коллизии
3. **SoundManager** - управление звуками и музыкой
4. **SpriteManager** - загрузка и кеширование спрайтов
5. **LevelManager** - загрузка и создание уровней
6. **ScoreManager** - управление рекордами
7. **EventManager** - система событий

### `js/main.js`

Точка входа в игру. Инициализирует все системы:

```javascript
// Импорты всех менеджеров
import { GameManager } from './managers/GameManager.js';
import { SoundManager } from './managers/SoundManager.js';
import { PhysicsManager } from './managers/PhysicsManager.js';
import { EventManager } from './managers/EventManager.js';

// Ожидание загрузки DOM
document.addEventListener('DOMContentLoaded', () => {
    // Получение canvas элемента
    const canvas = document.getElementById('game-canvas');
    
    // Установка размеров canvas (1024x768)
    canvas.width = 1024;
    canvas.height = 768;
    
    // Создание GameManager (который создаст все остальные менеджеры)
    const gameManager = new GameManager(canvas);
    
    // Инициализация игры
    gameManager.init();
    
    // Автоматический запуск видео меню, если меню активно
    const menuVideo = document.getElementById('menu-video');
    if (menuVideo && document.getElementById('menu-screen').classList.contains('active')) {
        menuVideo.play().catch(err => {
            console.warn('Не удалось автоматически воспроизвести видео:', err);
        });
    }
    
    // Сохранение gameManager в глобальной области для отладки
    window.gameManager = gameManager;
});
```

- **Строки 1-4**: Импорт всех необходимых менеджеров
- **Строка 7**: Ожидание полной загрузки DOM перед инициализацией
- **Строка 10**: Получение canvas элемента по ID
- **Строки 17-18**: Установка размеров canvas (1024x768 пикселей)
- **Строка 21**: Создание экземпляра GameManager, который создаст все остальные менеджеры

#### Основные методы:

**`init()` (строки 80-94)**: Инициализация игры
- Настройка UI (setupUI)
- Показ меню (showMenu) - воспроизводит фоновую музыку
- Загрузка рекордов (loadScores)

**`setupControls()` (строки 99-110)**: Настройка управления клавиатурой
- Обработка keydown/keyup событий
- Сохранение состояния клавиш в объекте `this.keys`
- Вызов handleInput() при нажатии клавиш во время игры

**`setupMouseControls()` (строки 115-128)**: Настройка управления мышью
- Обработка mousedown для атаки (левая кнопка мыши)

**`handleInput()` (строки 133-143)**: Обработка ввода
- A/← - движение влево (player.moveLeft())
- D/→ - движение вправо (player.moveRight())
- Space/W/↑ - прыжок (player.jump())

**`setupUI()` (строки 148-245)**: Настройка пользовательского интерфейса
- Использует делегирование событий для всех кнопок
- Обработка кликов по кнопкам:
  - `start-btn` - запуск игры
  - `scores-btn` - показ рекордов
  - `settings-btn` - показ настроек
  - `back-from-scores-btn`, `back-from-settings-btn` - возврат в меню
  - `toggle-sound-btn` - переключение звука
  - `restart-btn` - перезапуск игры
  - `menu-btn` - возврат в главное меню
  - `save-score-btn` - сохранение результата
  - `victory-*` - кнопки экрана победы

**`startGame()` (строки 250-270)**: Запуск игры
- Установка состояния 'playing'
- Сброс уровня, очков, жизней
- Показ экрана игры
- Остановка музыки меню, запуск музыки игрового процесса
- Загрузка уровня и запуск игрового цикла

**`loadLevel(levelNumber)` (строки 275-383)**: Загрузка уровня
- Получение уровня из LevelManager
- Очистка предыдущих объектов
- Загрузка tilesets (изображения тайлов)
- Загрузка фонового изображения
- Создание игрока
- Загрузка платформ, препятствий, врагов, бонусов, шипов, ворот
- Сброс состояния всех врагов
- Размещение врагов на платформах

**`gameLoop(currentTime)` (строки 388-402)**: Главный игровой цикл
- Проверка состояния игры (только 'playing')
- Вычисление deltaTime (время с последнего кадра, ограничено максимумом 2)
- Вызов update() и render()
- Запрос следующего кадра через requestAnimationFrame

**`update(deltaTime)` (строки 407-575)**: Обновление игровой логики
- Обновление игрока (update, checkAttackHit, физика)
- Обновление камеры (следует за игроком)

## Игровая механика

### Жизни и здоровье:
- Игрок начинает с **5 жизнями**
- Каждое столкновение с врагом, препятствием или шипами отнимает **1 жизнь**
- При сборе бонуса добавляется **1 жизнь**
- При достижении 0 жизней игра заканчивается

### Очки:
- Убийство врага: **100 очков**
- Сбор бонуса coin: **50 очков**
- Сбор бонуса health: **100 очков**
- Сбор бонуса powerup: **200 очков**

### Атака:
- Игрок может атаковать мечом (левая кнопка мыши или пробел)
- Система комбо: быстрые атаки чередуются между 3 типами (1→2→3→1)
- Окно комбо: 500 мс между атаками
- Зона атаки: 80x50 пикселей перед игроком
- Враг получает урон только один раз за атаку (защита от множественных попаданий)

### Враги:
- **Типы поведения:**
  - **patrol** - патрулирование в пределах 100 пикселей от стартовой позиции
  - **chase** - преследование игрока при обнаружении (≤250 пикселей)
  - **guard** - атака только при приближении (≤40 пикселей)
- **Типы персонажей:**
  - **Samurai** - обычный самурай (здоровье: 2)
  - **Samurai_Archer** - лучник (здоровье: 5, используется для босса)
  - **Samurai_Commander** - командир (используется для игрока)
- **ИИ врагов:**
  - Проверка прямой видимости игрока
  - Проверка на обрывы и шипы перед движением
  - Проверка шипов между врагом и игроком (не преследуют через шипы)
  - Остановка у границ уровня
  - Атака только на земле и на том же уровне, что и игрок

### Бонусы:
- **coin** - монета (50 очков, +1 жизнь)
- **health** - здоровье (100 очков, +1 жизнь)
- **powerup** - усиление (200 очков, +1 жизнь)
- Все бонусы добавляют жизнь при сборе

### Шипы:
- Наносят урон при контакте
- Проверка контакта:
  - При стоянии/ходьбе: нижняя часть игрока в пределах 15 пикселей от верха/низа шипов
  - При падении: нижняя часть игрока в пределах 5-10 пикселей от верха шипов
- Враги не переходят через шипы

### Врата:
- Ворота открываются, когда все враги на уровне побеждены
- При контакте с открытыми вратами - переход на следующий уровень
- Если уровней больше нет - показ экрана победы

### Камера:
- Плавно следует за игроком (lerp с коэффициентом 0.1)
- Ограничена границами уровня
- Масштаб: 2.0x (увеличение)

### Физика:
- **Гравитация:** 0.6 пикселей/кадр²
- **Высота прыжка:** -22 пикселей/кадр (начальная скорость)
- **Скорость игрока:** 5 пикселей/кадр
- **Трение:** коэффициент 0.8 (при отсутствии ввода)
- **Сопротивление воздуха:** коэффициент 0.98

```bash
./start-server.sh
```

**Windows:**
```cmd
start-server.bat
```

**Python 3:**
```bash
python3 -m http.server 8000
```

**Python 2:**
```bash
python -m http.server 8000
```

**Node.js (если установлен):**

```bash
npx serve
```

1. Откройте браузер
2. Перейдите по адресу: **http://localhost:8000**
3. Игра должна загрузиться и работать корректно

**Примечание:** Для остановки сервера нажмите `Ctrl+C` в терминале.

## Использование Tiled Editor

### Создание уровня:

1. Откройте Tiled Editor (www.mapeditor.org)
2. Создайте новую карту:
   - Размер тайла: 32x32 пикселя
   - Ширина и высота карты: по желанию (например, 60x20 тайлов)
3. Добавьте tileset:
   - Импортируйте `platforms_tileset.png` или создайте свой
   - Настройте размер тайлов (32x32)
4. Создайте слои:
   - **platforms** (tilelayer) - платформы для коллизий
   - **obstacles** (tilelayer) - препятствия для коллизий
   - **spikes** (tilelayer) - шипы для коллизий
   - **background** (imagelayer) - фоновое изображение (опционально)
   - **objects** (objectgroup) - объекты (player, enemy, bonus, endpoint, spike)
5. Разместите объекты:
   - **player** - стартовая позиция игрока
   - **enemy** - враги (добавьте свойства: type, characterType, health)
   - **bonus** - бонусы (добавьте свойство: type)
   - **endpoint** - точка завершения уровня (создаст Gate)
   - **spike** - шипы (объекты, не тайлы)
6. Экспортируйте в JSON:
   - File → Export As → JSON map files (*.json)
   - Сохраните в папку `levels/`

### Формат объектов в Tiled:

**Враг (enemy):**
- Свойства:
  - `type`: "patrol" | "chase" | "guard"
  - `characterType`: "Samurai" | "Samurai_Archer" | "Samurai_Commander"
  - `health`: число (например, "2" или "5" для босса)

**Бонус (bonus):**
- Свойства:
  - `type`: "coin" | "health" | "powerup"

**Шип (spike):**
- Объект с размерами (например, 32x32)
- Размещается на платформах

**Точка завершения (endpoint):**
- Объект с размерами (например, 80x100)
- Размещается в конце уровня
- Автоматически создаст Gate
